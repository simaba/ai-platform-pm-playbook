# AI Platform PM Playbook v0.1.0

**Publication status:** Draft release notes. Complete the public-release checklist before creating a public GitHub Release.

## Highlights

- Agent-product PRD template.
- Evaluation-plan template with hard-gate, quality-threshold, and evidence-completeness separation.
- Build-versus-buy framework that eliminates non-viable options before weighted comparison.
- Fully fictional worked example.

## Intended use

Use these as practitioner starting points for AI platform and agent-product work. Adapt every template to the actual context, accountable owners, and review process.

## Limits

The materials do not provide product, legal, procurement, security, privacy, compliance, or investment decisions. No fictional example is evidence that a real system is ready for release.

## Pre-publication record

Before publishing, record the reviewed commit SHA, review date, CI/check status, and confirmation that `docs/PUBLIC_RELEASE_CHECKLIST.md` was completed.
