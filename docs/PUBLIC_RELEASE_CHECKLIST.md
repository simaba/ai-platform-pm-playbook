# Public Release Checklist

Before making this repository public:

- [ ] Confirm all templates and worked examples are fictional, generic, or fully sanitized.
- [ ] Remove real employer, customer, supplier, contract, pricing, roadmap, architecture, evaluation, and negotiation material.
- [ ] Review all branches and full git history for information that should not become public.
- [ ] Review issues, PRs, comments, Actions logs/artifacts, releases, tags, attachments, and repository metadata.
- [ ] Confirm the README, templates, frameworks, and worked example agree on the current v0.1 scope.
- [ ] Confirm no framework implies a universal threshold, legal interpretation, or required vendor decision.
- [ ] Confirm CI, links, license, security policy, and contribution guidance are in a usable state.
- [ ] Create a draft GitHub Release first; review notes/assets before publishing.

This checklist does not replace employer, legal, security, privacy, procurement, or compliance review.
